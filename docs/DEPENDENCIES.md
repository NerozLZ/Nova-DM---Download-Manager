# Dependências

- **PySide6 (>=6.7)** — interface; é a única dependência Python de execução.
- **aria2** — motor de downloads, programa externo lançado como processo filho com `--stop-with-process`, RPC só em `127.0.0.1` com segredo aleatório por sessão.
- **SQLite** — módulo `sqlite3` da biblioteca padrão.
- **pytest, pytest-qt** — apenas desenvolvimento.
